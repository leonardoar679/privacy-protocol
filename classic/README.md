# Tornado Classic

An original-style interface for the existing Tornado Cash Classic pools on Ethereum mainnet (0.1, 1, 10 and 100 ETH),
with the original note format — the second product of the owner's "Privacy Wallet Web V1.1" document, frozen by
`../docs/privacy-wallet-web-spec-v3.0.md` §7. It is **a separate application**: its own `package.json` and
`package-lock.json`, its own Vite build served under `/classic/`, its own content security policy, budget, artifact
pins, tests, word policy and release gate, and its own licence (GPL-3.0 — the vendored original prover's). It shares
nothing at runtime with the Privacy Wallet in `../apps/web`: the design tokens arrive as a generated stylesheet
(`src/tokens.generated.css`, from `../packages/ui/src/tokens/tokens.css`, `npm run tokens`), nothing else crosses
(`../scripts/check-boundaries.mjs`, rule 9).

**Status (V7 Stage 8):** the package, the gates, the original-style screens on mock data (`docs/parity.md` against the
original, element by element; the Classic screenshot harness, axe and the word policy), the deployment verified against
Ethereum mainnet (`npm run verify-deployment`, `npm run test:live`), the cryptography (the original's own prover
vendored and converted without eval, proving in Node and in Chrome, its proofs accepted by the deployed verifier —
`docs/compatibility-matrix.md` §11), the history (`npm run snapshot`, the sync with checkpoints and rollback, the
IndexedDB store, every pool's frontier reproduced live — §12), and the relayers and the wallet: the protocol parsed as
real relayers speak it, the registry's rules, `npm run relayers` writing the curated `relayers.json` (23 live relayers
on 2026-10-26) whose hosts the policy allows, the deposit and withdrawal call data held to real transactions, the
wallets a page can see and one account on mainnet (§13). The data behind the screens is still `src/model/mock.ts` until the history, the
relayers and the flows arrive with Stages 7–9; the end-to-end runs and the release gate with Stages 10–11
(`../docs/roadmap.md`, the V7 table). **No build sends a transaction** until a pool function is switched live
(`VITE_CLASSIC_LIVE`) after its release-gate row and the owner's legal review (`classic/docs/release-gate.md`,
`classic/docs/legal-review.md` — Stage 11): every sending button reads "Not connected" and the banner says so on every
screen.

## Commands

```
npm ci                 # its own lockfile (never the root's)
npm run dev            # http://127.0.0.1:5174/classic/
npm run build          # tsc --noEmit, then vite build (dist/, with the policy meta and the manifest)
npm test               # vitest
npm run lint           # eslint
npm run gates          # words, declared dependencies, tokens, the vendored prover's conversion, the precompiled circuit, the pins
npm run copy-artifacts # the original circuit and proving key from ../reference/tornado-cli (or --from <dir>) into public/artifacts/, pinned
npm run compile-circuit # the circuit's templates as src/prover/generated/templates.js and the witness file (after copy-artifacts)
npm run vendor         # regenerate src/prover/legacy/ from vendor/ and the lists in scripts/vendor.mjs
npm run prover:browser # the prover in Chrome under the app's policy (after a build, with the artifacts)
npm run snapshot -- --pool eth-100 --archive https://eth.drpc.org   # a pool's history snapshot into public/data/eth-100 (the classic-ui clone as seed; a minute or two)
npm run relayers       # the curated relayer list relayers.json from the registry, ENS and every qualified relayer's status (two at a time; a few minutes)
npm run check-build    # dist, budget, pins (after a build)
npm run visual         # the screenshot harness (installed Chrome; UPDATE_BASELINES=1 rewrites the baselines — review them)
npm run verify-deployment -- --write   # the deployment against mainnet (public RPC; downloads the pinned compilers once): the pins + the report
npm run test:live      # the committed pins against the chain
```

`../scripts/verify-all.mjs` runs every gate above; CI installs this lockfile and runs them too.
